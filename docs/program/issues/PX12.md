## Objective — ✅ **operator-COMMITTED scope; the program's exit node**

Nonblocking-mode transitions; `epoll`/`eventfd`/`timerfd`/`signalfd` resources;
explicit one-shot/level/edge registration; **cancellation and timeout in the
operation type rather than in prose**; and normalized event observations for
differential tests.

★ **"In the operation type rather than in prose" is the whole design ruling.** A
timeout documented in a comment is not a contract; a cancellation that is not in
the type cannot be checked. This is the same principle as `ABI-M2`'s named
unavailability and `ABI-R3`'s derived enumeration: **make the machine carry the
claim.**

## This is the last node before the program exit (§6)

The program exits when a Ken **network service** and a **process supervisor** run
as native binaries, single-threaded and event-driven, with **no unsafe pointers
in application Ken**, and their **protocol state machines and path policy are
proved**.
