# teams/doc — doc-track lessons

Loaded by the **doc ring** — `doc-leader`, `doc-author`, and the **Librarian**,
which is the doc team's QA (there is no `doc-qa` seat). In addition to `fleet`
and the role scopes.

Doc-specific lessons about as-built currency, the attestation ledger, carrying a
review verdict across a fold, and the difference between a live derived claim and
a frozen historical quotation.

| Lesson | One-line |
|---|---|
| [a-currency-finding-can-be-a-ledger-dependency](a-currency-finding-can-be-a-ledger-dependency.md) | A stale quotation is often the visible corner of an attested-source dependency — trace every changed source through `SOURCE-ATTESTATIONS` before choosing a drive-by repair, and never sweep a frozen historical quotation |
| [carry-a-verdict-on-a-proved-delta-never-on-the-label-copy-only](carry-a-verdict-on-a-proved-delta-never-on-the-label-copy-only.md) | "Copy-only" is a claim about a fold, not evidence about it — bind `HEAD^` to the reviewed SHA and prove the delta before carrying a prior gate result forward |
