# roles/librarian — Librarian-specific lessons

Loaded by the Librarian, in addition to `fleet` and **`teams/doc`** — the
Librarian is the doc team's QA (there is no `doc-qa` seat), so it reads the doc
ring's team scope as well as this one.

This scope is for lessons specific to the Librarian's **two distinct hats**,
which no other seat combines:

1. **Doc-ring QA** — reviewing `doc-leader` / `doc-author` work packages.
2. **The standing as-built mandate** — no build QA holds this. The Librarian is
   accountable for `library/` remaining true about the system as built, which is
   a *continuous* obligation rather than a per-WP one.

**Lessons about the attestation ledger, as-built currency, and carrying a
verdict across a fold live in [`teams/doc`](../../teams/doc/README.md)** — put a
lesson there when it binds `doc-leader` and `doc-author` too, and here only when
it is specific to holding *both* hats at once (e.g. reviewing a WP whose subject
is a source your own mandate attests).
