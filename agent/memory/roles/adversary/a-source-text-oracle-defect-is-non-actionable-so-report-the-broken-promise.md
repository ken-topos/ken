# A source-text oracle's defect is non-actionable — report the broken promise

I filed that `RT-SCALE-B`'s emission census counts `.define_function(` over a
whole file including `#[cfg(test)]`, while a sibling pin over the **same roster**
strips the test module first. Measured, mutation-proven, correct.

⛔ **No node was filed, and not because I was wrong.** Operator ruling,
standing: *"Test oracles that assert facts about source code, catalog, or
documentation lines are an invitation for failure and delay. Tests should focus
on behavior."* ⇒ Reconciling two text-counting pins makes a disfavoured
instrument more precise and buys **zero behavioural coverage**. "The two pins
should agree" is aesthetic, and the node gate needs a grounded constraint.

## ⭐ The half that survived, and why

What the Steward recorded was **not** the disagreement. It was this: the
census's own comment states its job is to make a future roster addition
visible — and **a single count per file over a mixed population cannot do
that**, because a compensating swap holds the number constant.

⇒ **The instrument does not do what its comment claims.** That is a fact a
future reader will lean on and be wrong about. Same finding, and only this
framing has consequences.

## How to apply

- **Recognise the class early.** `source.matches(...)`, `include_str!` +
  `contains`, line counts, name inventories over text. A defect here will be
  **recorded, not repaired** — so ⛔ do not spend a long mutation budget proving
  a refinement nobody will act on. Confirm it cheaply and move on.
- **Lead with the broken promise, not the inconsistency.** Find the oracle's
  *stated* job — usually a `⭐`/`⛔` comment right above it — and show the
  mechanism cannot discharge it. [[audit-the-operative-line-not-the-stated-principle]]
  in reverse: there, prose over-claimed what code did; here, prose is the
  **standard** the code is measured against.
- ⚠ **A disfavoured oracle is still load-bearing while it exists.** Non-actionable
  is not harmless: it will be cited as coverage. Saying what it *cannot* see is
  the deliverable, and it costs one paragraph.
- **Do not stop hunting them** — just re-aim. The valuable output is the
  scoped-silence statement ([[a-clearance-names-the-axes-it-covers]]), not a
  repair proposal.

★ **The generalisable move:** when a finding lands in a class someone has ruled
non-actionable, the finding rarely dies — its *framing* does. Ask what a reader
would do differently knowing it, and report that. If the answer is "nothing,"
the finding really was aesthetic and you have learned something about your own
ranking ([[rank-subclaims-by-load-bearing-not-by-checkability]]).
